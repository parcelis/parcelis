title: Users
---

Open **Settings** from the sidebar to view the accounts created for the Parcelis workspace. The **Users** tab shows
each account's name, email address, phone number, role, and account status.

Select a user row to open that user's profile. Organization administrators can update the profile's name, email
address, and phone number.

Use the Actions menu to edit an account, disable or enable sign-in access, or permanently delete the account.
Disabled accounts cannot sign in until they are enabled again.

The **Roles** tab lists Administrator, Property Manager, Lease Manager, Maintenance, Property Owner, and Resident
Manager roles. Select **Manage access** to grant View, Create, Edit, Archive, and Delete permissions independently for
Properties, Units, Tenants, and Maintenance. Selecting a modifying action also enables View; clearing View clears the
other actions for that area.

Expand **Notes** to configure Property Notes, Unit Notes, Tenant Notes, and Maintenance Notes separately. The parent
Notes checkboxes apply an action to every note type and show a mixed state when the sub-items differ. A role must also
have View access to the record containing the note. For example, reading a unit note requires both Unit Notes View and
Units View. Notes do not support archiving. Administrator permissions are always enabled and cannot be changed.
