Notes store internal operating context for a property, unit, or tenant. Each note belongs to exactly one of those
records and includes its creation and last-updated timestamps.

Notes stay with their associated record and are removed when that record is permanently deleted. Open the Notes
drawer from a property, unit, or tenant page to manage its notes.

## Manage Notes

1. Select **Add Notes** in the page header.
2. In the **Notes** tab, enter a note and select the arrow in the lower-right of the text field.
3. Use the vertical actions menu on an existing note to **Edit** or **Delete** it.

The **Files** tab is reserved for future attachments.
