title: Unit Details
---

Use the **Unit Details** step in the property drawer to review, add, edit, or remove units for a property. Select a unit from its property's unit list to open its dedicated unit page.

## Unit Page

The unit page shows the unit's occupancy, type, market rent, bedroom and bathroom counts, square footage, and property address.

Use **All Units** in the page header to switch to another unit at the same property or return to the property page.

The page also provides these operational summaries when data is available:

- Current lease dates and status.
- Tenant contact information.
- Monthly rent, collected amount, and outstanding balance.
- Upcoming invoice amounts and due dates.
- Included utilities and amenities.
- Open maintenance requests, including their status, priority, and due date. Select a request to open its maintenance
  detail page.

## Edit a Unit

On a unit page, select **Edit Unit**. Parcelis opens the property drawer directly on the selected unit's expanded **Unit Details** card. Update the unit fields, then select **Save** to apply the changes.

## Notes

Select **Add Notes** in the page header to open the Notes drawer. Add internal unit context such as access
instructions, condition details, or renewal reminders. Use a note's vertical actions menu to edit or delete it.
The **Files** tab is reserved for future attachments.

## Unit Cards

Each unit appears as a card with these primary fields:

- Unit name.
- Market rate.
- Unit type: Residential or Commercial.

The card header also shows bedroom, bathroom, and square-foot summary chips. Empty values display as `0`.

## Expanded Details

Select **Unit Details** in a unit card to expand additional fields:

- Bedrooms.
- Bathrooms.
- Square feet.
- Included utilities.
- Amenities.

Utilities and amenities are loaded from Parcelis unit option records.

## Add a Unit

Use **Add Unit** to add another unit card to the property. New units must have a unit name, market rate, and unit type before the property can be saved.

## Remove a Unit

Use the trash action on a unit card to remove it from the property. Parcelis asks for confirmation before removing the unit from the edit form.
