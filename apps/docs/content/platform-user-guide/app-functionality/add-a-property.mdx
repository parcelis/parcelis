title: Add a Property
---

Use the property drawer when onboarding a new property.

## Required Fields

- Property address.
- Property name.
- Property type.
- Unit count.
- At least one unit with a unit name, market rate, and unit type.

## Optional Fields

- Address line 2.
- Property contact name.
- Property contact email.
- Property contact phone.
- Property contact address.
- Tags.
- A property image in JPG, PNG, or WebP format up to 2 MB.

## Steps

1. Select **Property** or **Add property**.
2. Enter the property address.
3. Enter the property name.
4. Choose the property type.
5. Enter the number of units.
6. Select existing tags or add a custom tag to organize the property.
7. Expand **Property Contact Info** if contact details should be stored with the property.
8. In the **Property Image** panel, to the left of the details form, select an image to upload. This is optional.
9. Select **Next** to open **Unit Details**.
10. Review the first unit card, add additional units if needed, and complete required unit fields.
11. Select **Create Property** to save the property and upload the selected image.

## Notes

- State fields are stored as two-letter uppercase regions.
- Unit count must be at least 1 when entered through the property drawer.
- Unit utilities and amenities come from Parcelis unit option records.
- If you close the drawer after making changes, Parcelis asks you to confirm before discarding unsaved work.
- Uploaded images are stored in MinIO under `properties/{propertyId}/images/{imageId}.{extension}`. Each property can have one current image; uploading a replacement updates the image used throughout Parcelis.
