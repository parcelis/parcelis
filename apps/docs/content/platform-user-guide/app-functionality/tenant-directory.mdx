The Tenants page is the main operating list for current, past, and archived tenants.

## What the Directory Shows

- Tenant name and contact information.
- Current property and unit when an active lease or lease in notice exists.
- Account status.
- Insurance status.
- Lease-derived tenant status.
- Lease end date or **Month-to-Month**.
- Row actions for viewing and managing the tenant.

The summary header shows the total number of tenants and counts for Active, Past, and Archived records.

## Search Tenants

Use the search field to find tenants by name, email, phone, property, or unit.

## Filter Tenants

Select **Filters** to narrow the directory by tenant status, account status, or insurance status. Select
**Apply Filters** to update the list or **Clear Filters** to reset it. The Filters button shows the active filter
count.

## Tenant Actions

Open the actions menu on a tenant row to:

- View the tenant detail page.
- Edit tenant details, emergency contact information, or the tenant image.
- Add or update internal notes.
- Archive an active or past tenant.
- Restore an archived tenant.
- Permanently delete a tenant.
