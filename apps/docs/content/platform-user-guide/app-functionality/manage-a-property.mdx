title: Manage a Property
---

Each property row includes an overflow actions menu.

On mobile, header actions collapse into the **Actions** menu. On larger screens, primary actions appear beside the menu.

## Edit a Property

Use **Edit Property** to update property details, address, unit count, type, or contact information.

The property drawer also includes **Unit Details**. Use it to add, edit, or remove unit cards associated with the property. Existing units appear in the edit drawer when they are available.

## Property Image

Use the **Property Image** panel below the property drawer menu to upload, replace, or delete the property image. Parcelis accepts JPG, PNG, and WebP files up to 2 MB. The current image appears in the panel, and the property landing page shows it beneath **Edit property** in the header.

Images are kept in the private MinIO bucket using `properties/{propertyId}/images/{imageId}.{extension}`. Replacing or deleting an image also removes its previous object from MinIO. Parcelis supplies short-lived upload and display URLs, so the storage bucket does not need to be public.

You can also open a unit page from the property's unit list and select **Edit Unit**. This opens the same property drawer with that unit expanded.

## Manage Tags

Use the **Tags** field in the property drawer to assign existing tags or add a custom tag. Tags are optional and can be updated whenever you edit the property.

## Remove a Unit

Use the trash action on a unit card to remove a unit from the property. Parcelis asks for confirmation before removing the unit from the edit form.

## Add Notes

Use **Actions → Add Note** in the property detail header to open the Notes drawer. Add internal property context such as ownership
preferences, access details, renewal reminders, or property-specific instructions. The drawer also includes a
**Files** tab; file attachments are not available yet. Use a note's vertical actions menu to edit or delete it.

## Archive a Property

Use **Actions → Archive Property** to hide a property from the default property list without permanently deleting it. Archived properties can be found by filtering for archived records. For archived properties, use **Actions → Unarchive Property** to restore them to the active list.

## Delete a Property

Use **Actions → Delete Property** only when the property should be permanently removed and has no history. Properties with leases, invoices, applications, maintenance, notes, or activity must be archived so their records remain available. Parcelis asks for confirmation before deleting.
