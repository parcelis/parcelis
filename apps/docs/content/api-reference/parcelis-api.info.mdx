Use an organization API token with Authorization: Bearer pcls_api_&lt;secret&gt;. Create tokens in Settings → Organization → API tokens. Tokens grant full access to the documented organization REST operations without granular scopes. No browser cookies or organization-selection header are needed. Health is public.
