Parcelis is organized as a pnpm workspace. Install dependencies, generate the Prisma client, then run the development tasks. `pnpm dev` starts the required local Docker services automatically.

```bash
pnpm install
cp .env.example .env
docker compose -f docker-compose-dev.yml up -d
pnpm db:generate
pnpm dev
```
